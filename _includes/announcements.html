BIL Data Center is Moving - Plan Ahead! Data access, validation, and publication services unavailable in October. Complete pending publications by mid-September. Read more Hide

The Pittsburgh Supercomputing Center (PSC) will begin relocating to a new data center facility this fall. The new data center will provide the advanced infrastructure needed to support PSC's growing computing and data-intensive research programs, ensuring continued service and innovation for the scientific community for years to come.

To minimize disruption, we expect the BIL data submission and metadata search services to remain available throughout the move. However, data access, data validation, and publication services will be unavailable in October until the migration is complete. Please take the following steps before the move:

  • Plan for an extended interruption to data publication services. Adjust project timelines and workflows accordingly.
  • Complete any pending data publications by mid-September. Data that has not finished the publication process before the October move may experience delays.
  • Clean up your project storage space. Files stored under the /bil/proj directory tree are not backed up. Delete data that is no longer needed and ensure that any critical files are backed up elsewhere.

Please note that PSC's Bridges-2 HPC system is currently scheduled to move after the BIL systems migration. If you use Bridges-2 to access or analyze BIL data, you will receive separate communications from the Bridges-2 project with details about that transition and any expected impacts.

Questions? Contact bil-support@psc.edu.
