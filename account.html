Creating an Account and Resetting Your Password

Create an account

Before you can connect to the BIL Analysis Ecosystem or deposit data in BIL, you must create an account. No account is needed to access and download public data deposited in BIL.

Steps Overview

  1. Create an ACCESS Account
  2. Request a BIL allocation in ACCESS
  3. Setup your BIL password
  4. Log in to BIL resources

1. Create an ACCESS Account

An ACCESS account is required to submit data to the Brain Image Library.

1.a Visit the ACCESS Website

Go to: identity.access-ci.org/new-user

1.b Provide Required Information

Enter the requested information, choose a username and complete the verification process to activate your ACCESS account.

2. Request an ACCESS Allocation for BIL

After creating yout ACCESS account:

  1. Log in to the ACCESS allocations dashboard: https://allocations.access-ci.org/
  2. Request a new "Explore" ACCESS Project
  3. Complete and submit the form.
  4. You will receive an email notification confirming your successful request. Once a decision has been made, you will receive a separate notification.

For more information on ACCESS Allocations, please see: https://www.brainimagelibrary.org/accessallocation.html

3. Exhange Credits for Allocation

After your ACCESS project is created, you will need to exchange the credits for storage resources.

For full ACCESS allocaiton instructions, see: https://allocations.access-ci.org/how-to

  1. First, login to​ allocations.access-ci.org

    • You’ll see your project information, or a list of your projects if you have multiple.

  2. Click on the “Credits + Resources” tab.

    • You can request multiple resources within one exchange.

  3. Click “Add a resource to your exchange.”

    • The list of available resources will then populate. You can find BIL under the "Storage Resources" section.

  4. Select a resource.

    • A required resource (oftentimes a storage resource) will automatically populate along with your selection.

  5. Enter the amount of units you’d like to request.

    • Request the amount storage that you anticipate using for your project.

  6. Enter a brief justification of why you’re requesting the resource(s).

  7. Click “Submit for Approval.”

    • A pop-up will then appear to “Complete Your Exchange.”

  8. Confirm the amounts being requested are correct, then click “Submit.”

    • You will receive an email notification confirming your successful request. Once a decision has been made, you will receive a separate notification.

4. Set Your Initial BIL/PSC Password

Use these steps to set an initial password or to reset an existing password:

  1. Visit apr.psc.edu
  2. Enter your username and email
  3. Enter the security code sent to your email
  4. Create your new password compliant with PSC passwork policies: https://www.psc.edu/user-resources/password-policies

Visit the Website: apr.psc.edu

To begin the password reset process, visit apr.psc.edu and click on the gray Start button on the bottom of the screen.

Enter the Required Information

To set (or re-set) your password, you will need to enter your PSC username and the email address that is on file at the center. The username is usually (but not always) the same as your XSEDE portal ID. The email address on file is usually (but not always) the email address associated with your XSEDE Portal Account.

Changing your password

To reset your password, visit apr.psc.edu and select the Begin Password Reset button. Follow the instructions by entering your username an email, and you will be sent a security code to use to finish the password change following the same steps used to set your initial password. See how to set your initial password for detailed instructions.

Reporting a problem

To report a problem on the Brain Image Library Analysis Ecosystem, please send an email to bil-support@psc.edu and include a detailed description of your issue, any error messages received, your user name, and any other key infomration to help us solve any issues quickly and effectively.
